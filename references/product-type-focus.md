# 产品类型拆解重心

先选择主类型，再使用对应检查项。不要把所有类型的清单机械地套到每个产品。

## AIGC 创作工具

重点是从意图到可交付资产的生产链：

- 输入模式：文本、参考图、完整脚本、媒体、模板；
- 生成阶段：构思、结构、实体、场景、分镜、媒体、合成；
- 模型：类型、能力、限制、质量、成本、延迟和路由；
- 一致性：角色、风格、场景、道具、时长、音画同步；
- 资产：稳定引用、版本、派生关系、复用、导出和版权；
- 异步任务：进度、取消、失败、重试、额度冻结；
- 完成门：单个素材完成与最终成品完成必须分开。

## 通用执行 Agent

重点是从用户目标到外部副作用的可控执行：

- 目标分解、计划、工具选择和重新规划；
- 授权边界、确认时机、敏感数据和外部通信；
- 工具 schema、调用结果、错误分类和幂等；
- 长任务、暂停或恢复或取消和多 Agent 协作；
- 记忆、项目上下文、运行状态和审计；
- 成功条件必须由外部结果验证，而不是 Agent 自述；
- 失败后重试、补偿和人工接管。

## 对话陪伴类产品

重点是关系连续性、记忆、安全和用户福祉：

- 角色设定、人格稳定性、语气和边界；
- 短期上下文、长期记忆、记忆编辑或删除和可解释性；
- 情绪识别、危机响应、依赖风险和未成年人保护；
- 隐私、敏感信息、数据保留和模型训练授权；
- 主动触达、通知频率和用户控制；
- 多模态、语音、延迟和实时性；
- 陪伴感与误导性人格声明之间的边界。

## 工作流或生产力 SaaS

重点是业务对象、协作、权限与集成：

- 核心对象、状态、视图、搜索和批量操作；
- 组织、角色、权限、共享和审计；
- 自动化、触发器、规则、审批和通知；
- 导入或导出、第三方集成、API 和 Webhook；
- 并发编辑、冲突、版本和恢复；
- 可靠性、可观察性、数据驻留和合规；
- AI 功能是否改变权威业务状态。

## 混合型产品

记录主类型和次类型，并说明本次主路径、类型切换点、最终权威状态，以及 AI 建议与真实执行的边界。

## 分类证据

优先使用真实任务路径、核心对象和用户最终成果分类。宣传页自称只作为辅助证据。
